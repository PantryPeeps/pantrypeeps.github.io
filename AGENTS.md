# Pantry Peeps website rules

- Keep the site compatible with GitHub Pages static hosting.
- Preserve the `CNAME` file and its exact value, `pantrypeeps.org`; do not disable HTTPS or change GitHub Pages custom-domain settings.
- Preserve `/deals/`, every existing deal record, affiliate destination, image file, image path, and disclosure unless Maria explicitly asks for a change.
- Before changing deal data or assets, compare the current repository and retain every existing record and referenced image.
- Keep affiliate disclosures clear and visible. Do not remove, weaken, or bury existing disclosure language.
- Add analytics without removing or replacing page behavior, metadata, styles, or deal functionality.
- Keep privacy content at `/privacy/` and link to it from every public HTML page footer.
- Use relative links and asset paths that work at both `/` and nested paths such as `/deals/`.
- Do not commit secrets, credentials, or private customer data.
- After site changes, verify links, asset paths, CNAME, deal data, disclosures, and the deployed GitHub Pages site.
